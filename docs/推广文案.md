## 版本 A｜朋友圈 / 公众号（长版）

**每一门课，都是一场闯关 —— KaleidoQuest 免费开放给老师了**

上课最怕什么？讲完一遍，不知道学生到底懂了没有。

KaleidoQuest 是我们文心书院做的课堂答题游戏。老师在大屏上开一局，学生用手机扫码加入，不用注册、不用下载，全班一起抢答。华文、数学、英文、科学都能用。

🎮 **两种玩法**
- **擂台抢答**：全班同一题，大屏倒计时，越快答对分越高，适合新课检查。
- **夺宝模式**：限时 5～10 分钟，各答各的，答对开宝箱，可能翻倍，也可能被偷分，适合复习。

✨ **出题不再花时间**
- 写一个主题，或者把课文贴进来，AI 一二十秒就出一套题。
- 华文输入生字就能出听音、拼音、部件题；数学选好运算范围就能生成。
- 游戏库里有现成游戏，覆盖华文、数学、英文、科学、常识和节日专题，复制过来就能改。
- Kahoot、Blooket 导出的题目表格也能直接导入。

📊 **每一局都有报告**
哪道题全班都错、谁还没掌握，一眼就看得到。也能把题包布置成作业，学生回家自己做。

🃏 **孩子会想再玩一局**
答完题能得到收集卡：44 张原创插画卡，还有每个汉字专属的「字灵」卡（部首、结构、字源都在卡上）。老师建好班级，学生登录后，卡册换设备也不会丢。
